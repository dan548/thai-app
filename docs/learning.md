# Ситуативное обучение

## Установка обновления

После защиты владельца и `save-grade.sql` выполни `learning-workflows.sql`,
затем актуальный `restore-backup.sql`. Это добавляет `phrase_decisions` и
`mission_results`; существующие фразы и прогресс не перезаписываются.
Обнови приложение после SQL. В действующем проекте SQL уже применён; для новой
базы порядок установки — в [manual-setup.md](manual-setup.md).

## Что изменилось

- «Я сейчас в…»: пять фраз на каждое место, в порядке реального разговора.
  Порядок определён вручную, отображаемый контент берётся из базы. Новые слова
  не вытесняют основные. Если нужная фраза отсутствует, показана заглушка.
- «Входящие»: чат и ручной ввод сначала требуют решения. Видео доступно после
  открытия ролика. «Учить» включает фразу в занятия, «Уже знаю» закрепляет,
  «Не нужно» исключает, «Отложить» сохраняет на потом. Решение можно изменить
  через «Все». Уже существующий прогресс сохраняет фразу в обучении.
- Видео: крестик ничего не добавляет. Выбор подтверждается отдельной кнопкой;
  «Учить сейчас» начинает занятие по выбранным словам. Прогресс виден у ролика.
- Миссия: подготовься, выполни действие, запиши результат, добавь услышанное.
  Позже открой «Прогресс» и проверь, помнишь ли нужную фразу. Показ и озвучка
  используют одинаковую частицу выбранного пола.
- Копия JSON v2 содержит решения и миссии. Копии v1 продолжают восстанавливаться.

## Проверка

`npm test` и `npm run build`; проверки БД — `security-check.sql` и
`learning-check.sql` (оба с откатом). Для проверки на телефоне:

1. Открой любое место: пять фраз идут по сценарию, свои реплики с твоей частицей,
   реплики собеседника сохраняют оригинальную частицу.
2. Добавь фразу вручную: она появляется во входящих, после «Учить» — в занятиях.
   Проверь «Отложить», возврат через фильтр и изменение решения.
3. Открой видео со словами. Закрой окно: слова не добавились. Вернись к разбору,
   выбери полезное и начни занятие. Если связи нет, выбор остаётся до повтора.
4. Сохрани заметку и выполнение миссии. После перезагрузки результат остаётся.
   На следующий день в «Прогрессе» доступна проверка памяти.
5. Экспортируй JSON: в нём есть `phrase_decisions` и `mission_results`.

Интерфейс проверен локально на тестовых данных при ширине 390 px: ошибка и
повтор сохранения миссии, проверка памяти, отложенные входящие, закрытие окна
видео без записи и явный выбор. Проверка телефона остаётся полезной для
Web Speech API и перехода между YouTube и установленным PWA.
