# Thai Trainer

Персональный тренажёр разговорного тайского. Мобайл-первый PWA: интервальное
повторение, шпаргалки «Я сейчас в…», мини-диалоги, тоны, слова из видео.
Контент выверен вручную, а установка идёт **как разговор с Claude или Codex** — помощник
персонализирует приложение под тебя и наполняет базу.

## Ключевая ценность
- Готовый выверенный контент (≈220 фраз в 7 темах, диалоги, тоны).
- Персонализация: имя, пол (вежливая частица), твои темы.
- Пять ситуативных шпаргалок с вручную заданным порядком фраз.
- Входящие: выбери полезное из чата, видео и ручного ввода.
- Миссия дня: подготовка, реальный разговор, заметка и последующая проверка.
- Пополнение фраз и слов из видео через чат с Claude или Codex (Supabase-коннектор).

## Быстрый старт (через Claude Code)
1. Форкни/клонируй репозиторий, открой папку в Claude Code.
2. Подключи Supabase-коннектор к Claude.
3. Скажи: **«настрой»** — сработает скилл `/setup`: опрос → база и владелец →
   контент → `.env.local` → запуск. По желанию задеплоит на Vercel. Понадобятся
   Node.js 22+ и email для входа владельца.

## Быстрый старт (через Codex)
1. Форкни/клонируй репозиторий, открой папку в Codex. Нужен Node.js 22+.
2. Подключи Supabase через MCP/коннектор в Codex и пройди авторизацию.
   Если подключения нет, помощник проведёт через те же действия вручную.
3. Скажи **«настрой»** или вызови **`$setup`** — помощник проведёт опрос,
   настроит базу и владельца, загрузит контент, создаст `.env.local`, запустит
   приложение и проверит работу. Пароль владельца задаёшь и вводишь сам.
4. По желанию попроси опубликовать на Vercel.

Навык находится в [.agents/skills/setup/SKILL.md](.agents/skills/setup/SKILL.md)
и загружается Codex из репозитория. Если он не появился, перезапусти Codex;
просьба «настрой» также обрабатывается через [AGENTS.md](AGENTS.md).
Существующая база с данными не переинициализируется автоматически.

Без AI-помощника: см. [docs/manual-setup.md](docs/manual-setup.md).

## Стек
Next.js (App Router) + PWA → Vercel · Supabase (напрямую с клиента) ·
озвучка Web Speech API (`th-TH`).

## Структура
- `app/page.jsx` — оболочка: вкладки, загрузка данных, SRS.
- `components/screens/` — экраны (Сегодня, «Я сейчас в…», Темы, Занятие,
  Диалоги, Тоны, Прогресс, Видео).
- `lib/srs.js` — интервальное повторение и стрик.
- `lib/profile.js` — имя и вежливая частица по полу.
- `lib/data.js` — оформление колод, реплики тайцев, диалоги, тоны, видео.
- `supabase/` — схема, защита владельца, функции, `seed.sql`, проверки (порядок — в
  [docs/manual-setup.md](docs/manual-setup.md)).

## Безопасность и резервные копии

Перед публичным использованием настрой вход единственного владельца и RLS
по [инструкции](docs/security.md). Публичный ключ сам по себе не защищает базу.
Экспорт и восстановление JSON доступны в разделе «Прогресс», включая решения
по фразам и результаты миссий. Новые сценарии описаны в
[docs/learning.md](docs/learning.md).
